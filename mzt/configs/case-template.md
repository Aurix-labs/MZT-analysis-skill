# 案例记录说明

仅在用户请求保存案例时使用。按案例实际内容组织，不要求填满固定栏目，也不自动追问满意度。

值得保留的是当时的目标和条件、实际依据、作出的判断、仍未确定的部分，以及后来发生了什么。分清建议、已执行的行动和观察到的结果；尚无反馈就保留为未验证。方法名称和漂亮的报告不能代替效果证据。

提炼经验时保留适用条件和反例，避免形成“遇到某类问题就套某方法”的新公式。一个案例不能证明普遍规律。

存储位置使用用户指定路径；用户选择本技能案例库时，可用 `cases/YYYY-MM-DD-主题.md` 并更新 [案例索引](../cases/INDEX.md)。存储可识别个人或组织的信息前遵循用户授权范围。
